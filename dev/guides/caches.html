Cache lifetime ​

Choose which values remain in memory, which also persist to disk, and what an invalidation removes. Plain property reads memoize; @cached adds disk storage. It does not make a property indexed or change whether it can be polled.

Memory ​

A repeated indexed call returns its stored value. fresh computes the selected property without reading or writing its cache.

julia
using DynamicObjects

@dynamicstruct struct Transform
    values::Vector{Float64}
    scaled(gain) = gain .* values
end

transform = Transform([1.0, 2.0])
first_read = transform.scaled(3.0)
(reused = transform.scaled(3.0) === first_read,
 fresh_is_distinct = fresh(transform.scaled, 3.0) !== first_read,
 original_still_stored = transform.scaled(3.0) === first_read)
(reused = true, fresh_is_distinct = true, original_still_stored = true)

The macro @fresh is the call-site form. A declaration marked @fresh uses that policy for each call. @memo! is retained for explicit cached access; ordinary indexed calls already memoize.

Treat returned arrays and other mutable results as read-only. Make a copy before changing them. Mutation would also change what later cache hits return.

Disk ​

Mark a property @cached to serialize its value. Put the cache in a location you control with __cache_base__. This example uses a temporary directory, so each documentation build starts with an empty disk cache.

julia
@dynamicstruct struct DiskSummary
    values::Vector{Float64}
    @cached v"1" total = sum(values)
end

cache_directory = mktempdir()
summary = DiskSummary([1.0, 2.0, 3.0]; __cache_base__ = cache_directory)
value = summary.total
(value = value, file_exists = isfile(@cache_path summary.total),
 ready = @is_cached(summary.total))
(value = 6.0, file_exists = true, ready = true)

The path is selected from the object's content identity, the property name, and any indexed arguments or version markers. Fixed fields and relevant constructor overrides participate in the default identity. Keep the identity inputs immutable. Change the declared cache version when a formula changes and existing files must no longer be reused.

A memory clear retains disk files. The trace records a disk read when the value is requested again.

julia
clear_mem_caches!(summary)
value, trace = with_compute_trace(() -> summary.total)
row = only(filter(row -> row.property == :total, compute_trace_rows(trace)))
(value = value, computed = row.computed, disk_reads = row.disk)
(value = 6.0, computed = 0, disk_reads = 1)

@mmap is the disk marker for supported memory-mapped values, including numeric arrays. Use it when retaining such arrays on disk is part of the application; keep its returned mapping read-only, like any other cached value.

Invalidation scope ​

OperationScope
invalidate!(object.property, arguments...)One indexed entry, memory and disk.
@clear_cache! object.propertyThe property and its declared dependents.
clear_mem_caches!(object)Derived memory values; retains disk files, constructor inputs and state.
clear_disk_caches!(object)Disk files; leaves memory values.
clear_all_caches!(object)Both memory and disk caches.
prune_mem_caches!(keep, object)Derived memory entries rejected by keep, without invalidating dependents.

An entry clear is narrower than clearing its whole property. If downstream properties also need to be recomputed, clear the property rather than only one argument tuple.

julia
invalidate!(transform.scaled, 3.0)
second_read = transform.scaled(3.0)
(same_values = second_read == first_read,
 recomputed_array = second_read !== first_read)
(same_values = true, recomputed_array = true)

Invalidation does not cancel an already running body. Its original caller can still receive the result, but the retracted computation cannot publish it back to the cleared cache. Waiters resolve against the current entry.

Instance state ​

Use @state for instance-owned state such as a lock or request counter. It is kept by memory clears and file synchronization. Its initializer may read fixed fields and other state properties, but not derived properties.

julia
@dynamicstruct struct Session
    @state requests = Ref(0)
    label = "ready"
end

session = Session()
session.requests[] += 1
clear_mem_caches!(session)
session.requests[]
1

Reset an individual state property with @clear_cache! session.requests. For a retained application's request context, remount creates a view that shares unrelated cached work while rebinding that context; it is distinct from replacing data inputs with remake.

Cached signal analysis traces repeated reads and property-wide invalidation through a dependency chain.
