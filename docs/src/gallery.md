# Gallery

A small live-rendered tour of the DynamicObjects concepts you'll meet most
often: derived properties, the disk-cache axis, indexed properties with
`@memo!`, and inline child structs. Each card is generated by the live
`DynamicObjectsWeb` app and recorded for the docs build — the same
markdown source serves both dev (live, via the Vite proxy on port 5174)
and production (the snapshots committed under
`docs/src/public/live-do/`).

```@raw html
<div class="htmxo-embed" data-hx-base="live-do/gallery" hx-swap="innerHTML">
  <em>Loading DynamicObjects gallery…</em>
</div>
```
